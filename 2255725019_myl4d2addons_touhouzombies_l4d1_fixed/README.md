
# touhou common infected l4d1 fix  

the touhou common infected mod ( https://steamcommunity.com/sharedfiles/filedetails/?id=2255725019 ) has improper animations for the common infected models added by dlc3  
this fixes those so that the animations match the ones on public servers, so that hitboxes are correct

currently this changes `common_female_nurse01.mdl`, `common_female_rural01.mdl`, `common_female01.mdl`, `common_male_baggagehandler_01.mdl`, `common_male_pilot.mdl`, `common_male_rural01.mdl`, `common_male_suit.mdl`, `common_male01.mdl`, `common_military_male01.mdl`, `common_patient_male01.mdl`, `common_police_male01.mdl`, `common_tsaagent_male01.mdl`, and `common_worker_male01.mdl`

i have tested maps no mercy, dead air, and death toll and all of them have correct zombie animations in public servers with this version of the mod
