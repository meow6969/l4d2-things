
# blue water but it replaces more water  

### to be used with [this addon](https://steamcommunity.com/sharedfiles/filedetails/?id=1305079670)  

this mod just makes the blue water effect apply to more water sources  
this mod copies and pastes water files from the original mod  

### normal & cheap water materials  

`$reflecttint     "{ RRR GGG BBB }"` -> `$reflecttint     "{ 0   64  128 }"`  
`$fogcolor        "{ RRR GGG BBB }"` -> `$fogcolor        "[ 0   64  128 ]"`  
`"360?$fogcolor"  "{ RRR GGG BBB }"` -> `"360?$fogcolor"  "[ 0   64  128 ]"`  
`"!360?$fogcolor" "{ RRR GGG BBB }"` -> `"!360?$fogcolor" "[ 0   64  128 ]"`  
 
`$color           "[ R.RR G.GG B.BB ]"` -> `$color        "[ 0.00 0.25 0.50 ]"`  
`$fogcolor        "[ R.RR G.GG B.BB ]"` -> `$fogcolor     "[ 0.00 0.25 0.50 ]"`  

### beneath water materials  

`$reflecttint     "{ RRR GGG BBB }"` -> `$reflecttint     "{ 0   32  64  }"`  
`$fogcolor        "{ RRR GGG BBB }"` -> `$fogcolor        "[ 0   32  64  ]"`  
`"360?$fogcolor"  "{ RRR GGG BBB }"` -> `"360?$fogcolor"  "[ 0   32  64  ]"`  
`"!360?$fogcolor" "{ RRR GGG BBB }"` -> `"!360?$fogcolor" "[ 0   32  64  ]"`  

`$color           "[ R.RR G.GG B.BB ]"` -> `$color        "[ 0.00 0.25 0.50 ]"`  
`$fogcolor        "[ R.RR G.GG B.BB ]"` -> `$fogcolor     "[ 0.00 0.13 0.25 ]"`
